## 原文校准要点

这次按 `/Users/easonliu/Downloads/W020220223593176860729.pdf` 重新核对了 2017 版原文，当前实现需要记住这些边界：

- 报文长度字段是数据段的 ASCII 字符数；当前 mock 按 UTF-8 字节切片兼容中文调试字段，不影响纯 ASCII 正式报文。
- `MN` 是固化在设备中的 24 位 `0~9,A~F` EPC-96 转换字符串。
- `Flag` 包含标准版本号、是否拆分包、是否应答；2017 版版本位为 `000001`，当前 `Flag=5` 表示 2017 版、不分包、需要数据应答。
- `9011` 是请求应答，`9012` 是执行结果，`9013` 是通知应答，`9014` 是数据应答；不是设备注册。
- 2017 版没有 2025 版强制新增的 `ST=44` 用电监控、`ST=45` 关键生产工况、附录 H 多媒体文件传输、SM4 国密加密要求。
- 2017 版已有 `CN=3020` 现场机信息、`CN=3019` 设备唯一标识、`ST=27` VOC 监测系统编码，但没有 2025 版 VOCs 原始监测数据/谱图的 `CN=2013` 定义。

## 报文示例

```text
##0242QN=20260621153000000;ST=31;CN=2011;PW=123456;MN=88888880000001;Flag=5;CP=&&DataTime=20260621153000;a21026-Rtd=35.20,a21026-Flag=N;a21002-Rtd=48.10,a21002-Flag=N;a34013-Rtd=8.60,a34013-Flag=N;a01012-Rtd=86.20,a01012-Flag=N&&ABCD\r\n
```

结构：

```text
## + 4位长度 + 数据段 + CRC + \r\n
```

数据段：

```text
QN=20260621153000000;
ST=31;
CN=2011;
PW=123456;
MN=88888880000001;
Flag=5;
CP=&&DataTime=20260621153000;...&&
```

## Flag 版本位

2017 原文中 `Flag` 的 8 位结构为：

| 位 | 含义 |
|---|---|
| `V5～V0` | 标准版本号 |
| `D` | 是否有数据包序号，1 表示包含 `PNUM/PNO` |
| `A` | 命令是否应答，1 表示需要应答 |

版本号：

| 版本位 | 标准 |
|---|---|
| `000000` | HJ/T 212-2005 |
| `000001` | HJ 212-2017 |

当前统一使用：

```text
Flag=5
```

二进制：

```text
00000101
```

含义：2017 版、不拆分包、需要应答。

## 正式接入时怎么改

### 作为上传网关

1052/Node-RED 采集现场数据后，按 HJ212 上传环保平台：

```text
Modbus / OPC UA / MQTT / PLC
  → 因子映射
  → 生成 HJ212 CP
  → 计算长度和 CRC
  → TCP out / HTTP request 上传平台
```

需要修改：

```js
flow.set('hj212_mn', '正式 MN');
flow.set('hj212_pw', '正式 PW');
flow.set('hj212_st', '31 或 32 或 38');
flow.set('hj212_baseUrl', '环保平台地址');
```

并把 `生成 HJ212 因子数据` 替换为真实采集值。

### 作为接收平台

如果第三方数采仪向 1052 上传 HJ212：

```text
TCP in / HTTP in
  → 解析 HJ212
  → 校验长度 + CRC
  → CP 因子展开
  → POST /api/td/insert 写入 TDengine
```

下一步可以在当前 flow 基础上增加 `TCP in :9001` 和写入 1052 的 `/api/td/insert`。

## 注意事项

1. 长度字段是数据段 UTF-8 字节长度，不包含 `##`、长度本身、CRC、`\r\n`。
2. CRC 只对数据段计算。
3. 不同平台可能存在 CRC 字节序差异，正式接入前必须用对方样例报文校验。
4. `Flag=5` 是 2017 版常用配置：版本位 `000001`、不分包、需要应答；若不需要数据应答可调整最低位。
5. `MN/PW` 是现场敏感配置，正式版本应走 1052 前端配置或 Node-RED credentials，不要写死。
6. `CN=2011` 是实时数据，`CN=2051` 是分钟数据，`CN=2061` 是小时数据，`CN=2031` 是日历史数据。
7. 因子编码要和环保平台备案表一致，不能随便自定义。
8. 2017 版不强制 SM4/多媒体/用电工况；这些能力按 HJ212-2025 flow 独立实现，保留 2017 flow 兼容老平台。
